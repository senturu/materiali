Admin – CF HUB materiali

1 · Collegamento a GitHub

Serve per salvare le modifiche direttamente nel repository, senza scaricare e ricaricare i file a mano. Crea un token fine-grained su GitHub (Settings → Developer settings → Fine-grained tokens) limitato a questo solo repository, permesso Contents: Read and write. Il token resta solo in questo browser (se spunti “ricorda”), non viene mai scritto nel repository. 






 
2 · Elenco CF (cf.json)

 Carica l’Excel (colonne: Email, Dominio, Stato Sito, Nome, Cognome; facoltativa: Codice Fiscale o Sesso per il genere). Senza codice fiscale il genere è dedotto dal nome: verifica l’elenco “da controllare” e correggi con le eccezioni.

3 · Materiali (flyer, brochure…)

 Qui aggiungi o modifichi i materiali che i CF possono personalizzare: carichi il PDF, indichi con il mouse dove va il QR, imposti scritte e messaggio WhatsApp. Il salvataggio avviene su GitHub (serve il punto 1). Non serve alcuna ricostruzione del sito.
